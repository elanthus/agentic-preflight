- Add `agentic-preflight audit [--output PATH] [--local-details]`, which writes a run's audit trail as one self-contained HTML file: what the record proves and does not prove, the intent, who acted (with self-reported values marked apart from measured ones), each stage, each finding and its resolution, the event timeline, the event log's hash chain, the attestation note and whether it verifies, and what was gated and pushed. It changes no run state and works for a run in any state; to check that the run is between commands it takes the run's operation lock for an instant without waiting, so a `start --replace` or `gc` at that moment treats the run as busy. By default it leaves out local paths, user-level configuration and commands, and Git remote URLs, and it shows a remote's name in a `refs/remotes/` ref as `<remote>`; it keeps a short ref such as `origin/main`, and it still holds finding text, notes, and the intent as written, so read it before you share it. `--output` inside the repository's Git directory, onto a worktree's `.git` file, or onto a directory exits 3 with `output_refused`. See the [example report](https://github.com/elanthus/agentic-preflight/blob/main/docs/examples/audit-report.html).
