- Add `agentic-preflight audit [--output PATH] [--local-details]`, which writes a run's audit trail as one self-contained HTML file: what the record proves and does not prove, the intent, who acted (with self-reported values marked apart from measured ones), each stage, each finding and its resolution, the event timeline with raw events, the event log's hash chain, the attestation note, and what was gated and pushed. It changes no run state, works for a run in any state, and by default leaves out local paths and user-level configuration so the file can be shared. See the [example report](docs/examples/audit-report.html).
