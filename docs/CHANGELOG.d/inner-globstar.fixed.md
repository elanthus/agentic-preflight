- Match an inner `**` segment against zero directories, as Git does. A pattern such as `src/**/secrets.py` in `[policy]`, `trusted_paths`, `[diff] exclude`, `[docs] paths`, or the grounding sources now also matches `src/secrets.py`. Previously it required at least one directory in between, so a protected file directly under `src/` was classified at a lower risk. A run of `**` segments now means the same as one, as in Git. A trailing `/**` still does not match the directory itself.
