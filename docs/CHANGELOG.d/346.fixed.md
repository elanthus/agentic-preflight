- The fresh-base rebase no longer follows `rebase.updateRefs`, so `start` never rewrites a
  branch stacked under the validated branch. It also ignores `rebase.autoSquash`,
  `rebase.autoStash`, `rebase.rebaseMerges`, and `pull.twohead`, which made it rebase a
  dirty checkout, keep merge commits, or drop the branch's changes.
- The fallback base merge ignores `pull.twohead`, `merge.verifySignatures`, and `merge.log`,
