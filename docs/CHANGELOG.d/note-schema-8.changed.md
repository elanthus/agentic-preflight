- Attestation notes move to schema version 8, and schema 7 notes no longer verify. This breaks compatibility. Upgrade the CLI, the pre-push hook, and the protected verifier together, and validate open pull requests again. See `COMPATIBILITY.md`.
- A schema 8 note adds `producer` (the run's tool, interpreter, platform, and self-reported client and model, each claim with its source), `events` (the event chain's `head_sha256`, `lines`, and `chained_lines` at merge-back), `transcripts` (the digest and size of each recorded reviewer transcript), and `records` (null, or the records bundle commit). Every key must be present.
- `events --verify` and `mergeback` report `anchor_mismatch` when the run's note anchors its event log and the log's anchored prefix was removed or rewritten.
