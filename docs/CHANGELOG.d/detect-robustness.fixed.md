- Command detection skips a non-UTF-8 `Makefile`, `justfile`, or `pyproject.toml` and a `package.json` whose top level is not an object instead of failing with `internal_error`. A script or target now matches a stage only when one of its words, split at any character other than a letter or digit, is the stage name or its plural (`test:unit`, `unit-tests`) or a known tool for that stage (`pytest` and `unittest` for test), so `latest` and `contest` are no longer offered as test commands.
