- Add `[attestation] require_signature`. When the trusted base sets it to `true`, `verify SHA --signature` fails with `signature_required` and exit 2 for a note that has no signature from the protected verifier, whatever the cause. It defaults to `false`, stays out of run snapshots and configuration digests, and does not affect plain `verify SHA`. See [ADR 0004](https://github.com/elanthus/agentic-preflight/blob/main/docs/adr/0004-sign-verified-attestations.md).
