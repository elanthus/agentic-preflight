- Add `[records] publish` (default `false`). When it is `true`, `mergeback` builds a records bundle, one parentless commit with a neutral identity that holds the exact intent text, the stored stage logs, the reviewer transcripts, a redacted copy of the event log, and a manifest. The note names it in `records.commit`, and `push` publishes it as an evidence ref before the branch. Stage logs are published as stored and can hold local paths and anything the command printed.
- `verify SHA` checks a bundle the note names against the note's digests and anchor, without a fetch of its own, and reports what it checked in `data.records`. It fails with `missing_records`, `records_mismatch`, or, when the protected base sets `[records] publish = true` and the note names no bundle, `records_required`.
