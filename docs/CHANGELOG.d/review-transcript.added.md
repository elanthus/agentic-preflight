- Add `submit-findings --transcript PATH` for an agent that reviews in-harness or reviews the docs stage. The CLI keeps a redacted copy of the agent's own review notes as `logs/review-transcript.txt` or `logs/docs-transcript.txt` in the run directory, appends a `transcript_recorded` event with the stage, SHA-256, byte count, and `source` `flag`, and returns `data.transcript_sha256`, `data.transcript_bytes`, and `data.transcript_path`. A transcript over 1 MiB or not valid UTF-8 exits 3 with `invalid_findings` and records nothing. The transcript is the agent's claim and does not enter the attestation note or the stage fingerprint.
