- `start` now records the current branch by its full ref, so a branch that shares its name
  with a tag is recorded as `<name>` instead of `heads/<name>`. Previously `push` then
  reported success after creating `refs/heads/heads/<name>` on the remote and left the
  real branch unchanged. A `HEAD` that points at a ref outside `refs/heads/` is refused
  rather than recorded as a branch.
